ICONS

Icon character

One toolbar — search, filter, date range, export, chart, members, settings — in each style's stroke language. Shapes here are representative at a 24px grid; the real decision is weight range and ecosystem fit.

Lucide — one weight, 1.5–2px rec
Already wired; every shadcn block ships with it. Add ~10 Tabler glyphs only for funnel / cohort / pivot.
Phosphor — six weights (thin→fill→duotone)
Expressive; duotone reads well on a marketing home. Means re-iconing every shadcn component.
Tabler — 2px stroke, 6,000+ icons
Best coverage for niche data glyphs; stroke sits close to Lucide. Good as a supplement, not a base.
